### Строка `run:` читается так, как её читает оболочка

Прошлая починка звала `shlex` — и внешний взгляд показал, что он для этого не
годится **двумя** способами сразу.

**Кавычки терялись вместе с комментарием.** `shlex` отдаёт токены, и собрать из
них строку обратно нельзя: `echo "a | b"` превращался в `echo a | b`, то есть в
две команды вместо одной. Докстрока обещала «кавычки уважаются» — уважены они
были только при поиске комментария, а соседям по разбору доставалась строка без
них.

**Правило комментария у `shlex` шире оболочкиного.** Он режет по решётке и
внутри слова: `echo foo#bar` → `echo foo`, чего `bash` не делает. А
`pip install pkg@git+URL#egg=x` — обычный адрес, и такой шаг молча терял хвост
команды.

Теперь разбор свой и строку **не пересобирает**: он находит границу и отдаёт
исходный кусок. Три правила, каждое измерено:

| решётка | комментарий? |
|---|---|
| в начале строки или после пробела | да |
| внутри слова (`pkg#egg=x`) | нет — как в оболочке |
| в кавычках (`echo "…#196"`) | нет — таких строк в дереве четыре |

Связки (`&&`, `\|\|`, `;`, `\|`) теперь тоже режут **только вне кавычек**.

**Состав служебных на живом дереве прежний:** те же шесть имён.

**Проверено откатом, каждая половина поимённо:** решётка в слове снова
комментарий — краснеет одна проверка; кавычки не мешают резать по связке —
одна; комментарий в кавычках снова режет — одна.
