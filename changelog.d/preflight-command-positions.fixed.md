### Предполётная узнаёт вызов `pytest` по позиции команды

Слово «выбор не применён — набор идёт целиком» печаталось и у шага без
тестов: `cat pytest.ini` или `pip3 install pytest` считались вызовом. А шаг
`pip install -e . && pytest` получал «прикладывать не к чему», хотя набор
шёл. Теперь вызов ищется в позиции команды — после `&&`, `|`, `;`, `then`,
за приставками `timeout`, `time`, `exec` и `X=1`, голым словом или
`python -m`. Разбор этот один, и тест сверки прокладок пользуется им же.
