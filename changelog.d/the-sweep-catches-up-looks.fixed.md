### Вытесненная запись находок догоняется

Запись находок взгляда идёт через группу конкурентности `findings-write`.
Площадка держит в ней один ожидающий прогон, и новый отменяет прежний.
**Замер 25.09.2026** по 1000 прогонам `review.yml`: за неделю отменено 7 записей
из 662. Следующая запись читала только свой заход, и находки вытесненного
захода, которых она не повторила, пропадали без следа.

Теперь реестр находок помнит, какой заход записан у каждого изменения
(строка «Записано: #N@<id вердикта>»). Запись находок дописывает все заходы
после отмеченного, а уборка (`sweep`) делает то же для открытых изменений и
для отмеченных. По слитому изменению уборка догоняет в последний раз и снимает
отметку, поэтому запись, вытесненная прямо перед слиянием, тоже доходит.

**Предел назван:** у изменения без отметки догоняется только последний заход.
Перечитывать всю ленту нельзя: вернулись бы уже снятые находки.

**Проверено откатом:** запись только последнего захода, уборка без догона,
уборка только по открытым, неснятая отметка слитого и чтение всей ленты без
отметки — каждое краснеет своим тестом.
