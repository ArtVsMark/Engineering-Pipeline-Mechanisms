### Гейт имён репозиториев спрашивает площадку только о настоящих именах

Гейт `check_own_name` собирал имена репозиториев из всех отслеживаемых файлов и
о каждом спрашивал площадку. В переписи были и образцы из `tests/` (`o/r`,
`someone/…`), и «имена» с владельцем `repos`: в адресе API сегмент пути
`repos` читался владельцем. Теперь каталог `tests/` в перепись не входит,
а адрес API разбирается своей ветвью образца.

**Замер 03.10.2026** (счётчик запросов, живой прогон гейта): запросов к
площадке 18 → 6.
