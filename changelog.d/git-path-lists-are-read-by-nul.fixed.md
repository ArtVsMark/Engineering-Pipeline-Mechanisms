Три дефекта, каждый из которых оставлял проверку зелёной и слепой, найдены при
разборе правил каталога и закрыты гейтами.

- **Список путей из git читался построчно.** `agent_pr` и шаг «тронутые файлы»
  звали `git diff --name-only` без `-z`: путь с пробелом или не-ASCII приходит
  экранированным, не разрешается и молча выпадает из отбора зон — метка не
  выставится, а гейт останется зелёным. Теперь `-z` обязателен, список
  передаётся в проверку файлом (`--files-from`), а не подстановкой, потому что
  оболочка вырезает NUL. Каждая проверка, читающая список путей, печатает охват:
  сколько прочитано и сколько пропущено.
- **`subprocess.run(text=True)` брал кодировку у локали раннера.** Пять вызовов
  получили явное `encoding="utf-8"`: такой дефект краснеет только при совпадении
  ячейки матрицы и подходящих данных, поэтому зелёная матрица о нём не говорит
  ничего.
- **Имена переменных оболочки** проверяются на латиницу: не-ASCII имя создаётся
  штатно, а подстановка выходит пустой, и условие всегда идёт одной веткой.
