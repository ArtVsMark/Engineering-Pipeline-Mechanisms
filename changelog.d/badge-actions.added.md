### Значки проекта рисуют механизмы: три действия и общий шаг фактов

Рисовальщик значков переехал из каталога (#1563). Новые составные действия
`python-badge`, `family-badge` и `project-badge` — для тех, кто рисует значки
вне общего шага фактов: зовутся по тегу механизмов, Python ставит вызывающий.
`step-facts` теперь рисует значок проекта нашим `project_badge.py --parts` из
своей выкачки, а не действием каталога: отдельного пина больше нет, и «собран
с серым» отличим от «не собран». Картинка у потребителя та же; «machine»
считается по видам `kinds.MACHINE`, как в фактах.
