### Страж толчка судит голову того дерева, которое толкают

Хук окна `push_guard` читал текущую ветку в каталоге, где запущен сам, —
в дереве проекта. Окно, которое ведёт второй репозиторий, не могло толкнуть
его ветку `agent/…` ни через `cd <путь> && git push`, ни через
`git -C <путь> push`: страж сверял толчок с головой не того дерева. Теперь
каталог толчка берётся из каталога события, из `cd` той же строки и из `-C`
у `git`, и голова со следами слитой ветки читается там. Каталог, который не
узнать (`cd -`, переменная, `--git-dir`), — отказ с причиной.
