### Витрина ведёт на таблицу «кем»; гейт правила 089 сужен до его буквы

README ведёт текстовой ссылкой на таблицу `who.md` — кто из семьи зовёт наши
шаги по тегу. Гейт `tests/test_no_link_into_the_copy.py` запрещал текстом любой
адрес производного, а правило 089 говорит о копии оригинала: у таблицы «кем»
оригинала в дереве нет — её данные приходят из обхода чужих деревьев, — и
ссылка на неё никуда «в прошлое» не уводит. Такие адреса гейт теперь знает
перечнем исключений с причиной — целиком, с веткой и путём, — а основание
«оригинала в дереве нет» держит сборка фактов без обхода клонов.
