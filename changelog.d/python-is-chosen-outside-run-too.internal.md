### Гейт «python не раньше установки» видит вызовы вне строки оболочки

Гейт искал вызов python только в строке `run:`. Теперь вызовом считается и
шаг агента взгляда — агент зовёт `python3 -m pytest` из текста задания, —
и шаг с `shell: python…`, и составное действие из дерева (`uses: ./…`) по
шагам его `action.yml`; не найденное составное действие считается
вызовом. Установка узнаётся по точному имени действия, а не по подстроке.
