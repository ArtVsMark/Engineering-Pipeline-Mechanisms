### Планка Python — 3.14

Механизмы требуют Python 3.14 и новее: так решено для всей семьи. Все общие
шаги и прогоны ставят 3.14, матрица проверок сжата до одной версии.

- Было: пакет транспорта `engineering-pipeline-transport` ставился на Python
  3.12 и новее, `VERSION` — 0.2.0. Стало: он требует `requires-python >=3.14`
  и пишет `except A, B:` без скобок (PEP 758), поэтому на 3.12 и 3.13 не
  ставится и не импортируется; `VERSION` — 0.3.0. Соседу, который ставит
  транспорт по тегу (решение 024), нужен Python 3.14 вместо прежнего.
- Предрелизный Python 3.15 проверяется отдельным прогоном `python-next.yml`
  (#1029), а код переписан под 3.14 следующими изменениями (#1036).
