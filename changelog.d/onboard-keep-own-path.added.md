### Подключение оставляет проекту его путь ключом `--keep`

`onboard.py --write --keep ПУТЬ` не пишет путь, который проект оставляет своим,
— свой выпуск пакета, свои значки, — и не считает его занятым. Проверки
прогона по этому пути ложатся в `.pipeline.yml` классом `off` с причиной.
Путь, которого заготовка не кладёт, — отказ; занятый путь без ключа — прежний
отказ с кодом 5.
