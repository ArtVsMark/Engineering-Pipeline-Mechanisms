### Память дат верификатора читается и в приватном репозитории и уступает дате площадки

Шаг `verify-queue` читал архив находок прямой ссылкой без токена, и в
приватном репозитории память дат слияния была пуста всегда. Теперь архив
читается API площадки с токеном захода. Дата слияния у номера из окна
площадки берётся у неё, а память архива — только для номеров вне окна: память
хранит время коммитера, и переписанная история его сдвигает. База находок
(`scripts/findings_db.py`) получила таблицу `merges` с датами слияния.
