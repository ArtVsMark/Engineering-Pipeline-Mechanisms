### Обход клонов семьи: у соседа свой предел ниже бюджета, у шага — запас

Каждый вызов git у соседа ждал `min(TIMEOUT, остаток)` при `TIMEOUT` 120 с и
бюджете 75 с, то есть своего предела ниже бюджета у соседа не было: первый
повисший сосед съедал весь бюджет, и остальные выходили непрочитанными.
Теперь `TIMEOUT` — 25 с на вызов, оба вызова соседа короче бюджета, и это
держит тест. Худший случай обхода — `BUDGET + TIMEOUT`, и предел шага в
`badges.yml` сверяется с ним вместе с запасом `STEP_MARGIN` на запуск Python и
уборку клонов; уборка клонов больше не роняет отчёт, если потомок git ещё
пишет в каталог. Прежнее «худший случай — вдвое больше бюджета» больше не
верно.
