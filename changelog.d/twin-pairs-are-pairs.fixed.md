### Строка снятия «A дубль B, C дубль D» читается парами, а не цепочкой

Общий разбор снятий (`changerefs`) приписывал двойника каждому отпечатку
группы по первой цели следующей группы. Пары через запятую поэтому читались
цепочкой: цель первой пары получала двойника второй. Сверка архива с
историей (#864) нашла так 11 ложных связей из 107.

Теперь грамматика записана и различает формы:

- `A дубль B` — A→B;
- `A, C дубль B` — A→B и C→B;
- `A дубль B, C дубль D` — A→B и C→D;
- `A дубль B дубль C` — цепочка A→B, B→C;
- `A дубль B, C` — A→B, а C снята сама.

Независимая сверка архива читает те же формы своим прямым правилом. Перечитка
архива теперь пересчитывает связи по всей истории, а не только дописывает:
ложная связь прежнего разбора иначе пережила бы её. На настоящем архиве
перечитка дала 96 связей и ни одной без пары.

**Проверено откатом:** прежнее правило краснит случаи «пары» и «пара и
список», а перечитка без пересчёта краснит `test_reread_recomputes_a_wrong_link`.
