целым, совпадения не выходило, и пункт не отмечался: механизм говорил «пункт не
найден», а человек видел в теле изменения огрызок своей строки.

Тем же чинится снятие находки: отпечаток, взятый в кавычки, раньше терялся
молча — запись оставалась в живой задаче, хотя находка была починена.
