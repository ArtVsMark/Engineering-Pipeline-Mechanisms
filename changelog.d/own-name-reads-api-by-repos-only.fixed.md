### Гейт имени читает адрес API только по `/repos/…` и называет неответившее

`check_own_name.py` у хостов `api.github.com` и `uploads.github.com` считает
именем репозитория только путь `/repos/<владелец>/<имя>`: `user/repos`,
`gists/…`, `networks/…` больше не принимаются за владельцев и не стоят
запроса. Имена, на которые площадка не ответила, считаются отдельно и
печатаются числом — «чисто» больше не скрывает несверенные.
