### Облачное окно стартует с окружением проверки на планке

Окно агента в облаке открывается без окружения, на котором предполётная может
пообещать «площадка скажет то же»: системный Python там ниже планки. Теперь
это собирает хук старта. Окружение собирается на версии из `requires-python`
с инструментами в границах из строк установки прогонов; планка теперь
Python 3.14, и хук ставит его сам. Вне облака хук не делает ничего. Сбой
сети не роняет старт: хук называет, что не собрано, и окно открывается.
Годное окружение не переставляется, поэтому окно без сети получает уже
собранное. Пакеты дерева ставятся редактируемой установкой, и правка пакета
видна тестам сразу.
