### Шапка README и витрина переходят на единый значок `python.svg`

Значок опубликован на ветке `badges` первым прогоном шага, и ссылка на него
въезжает вторым изменением, как требует правило 196. Ответы витрины «зелены ли
проверки», «какой выпуск», «какая версия» и «какое покрытие» дают зоны
единого значка.

- Было: на ветке `badges` лежал `release.json` — значок последнего выпуска.
  Стало: он не публикуется. Выпуск показывает зона «release / PyPI» единого
  значка, которая спрашивает площадку сама, — но только два старших числа и
  серым: PyPI у механизмов нет. Номер правки (третье число тега, к которому
  прибиваются) значок больше не показывает; полный тег — на странице выпусков.
  Если внешняя ссылка указывала на `release.json` ради полного тега, ведите её
  на страницу выпусков, а не на `python.svg`.
- Было: в шапке README стояли отдельные значки версии, выпуска и покрытия.
  Стало: один `python.svg`. Файлы `version.json` и `coverage.json` остаются на
  ветке — из них единый значок берёт свои зоны.
