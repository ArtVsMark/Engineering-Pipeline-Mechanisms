### Выпуск и счёт окна без git отказывают, а не падают трассой

Обёртки вызова git у выпуска и у счёта срока окна не ловили отсутствие git:
без него на пути механизм падал трассой вместо третьего исхода. Обе теперь
идут тем же общим вызовом git, что и остальные механизмы. Длинный ответ git в
отказе обрезается с пометкой, сколько в нём было знаков.
