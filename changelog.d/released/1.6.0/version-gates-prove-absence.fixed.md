### Гейты версии говорят «неприменимо» только по доказанному

`version.py --check` без тега и `CONTRACT_VERSION` отвечает «неприменимо»,
только когда git отвечает, клон полный и источник выпускных тегов не несёт;
вне репозитория — отказ, при тегах у источника или его молчании — третий
исход с подсказкой. `check_version.py` сначала получает список файлов, а без
источника версии ловит маркер контракта, который переписать нечем.
