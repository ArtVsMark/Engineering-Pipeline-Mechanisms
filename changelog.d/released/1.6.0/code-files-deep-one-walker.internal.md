### Гейты набора обходят источники одним глубоким обходчиком

Восемь гейтов обходили корни кода своими копиями неглубокого обхода и
пропустили бы вложенный каталог молча. Теперь все корни — источники, набор,
перехваты `.claude/hooks` — идут через один `conftest.code_files`: вглубь и по
тому, что git считает деревом (отслеживаемое и новое, без игнорируемых
`build/` и `__pycache__`); вне git — отказ с причиной. Гейт меток узнаёт
объявления во всех источниках. Пробы на подделке дерева держат обе стороны.
