### Ответ каталогу, слежка и записи решений — по таблице путей проекта

Семь механизмов с `--root` берут адреса данных проекта из раздела `paths:`
вашего `.pipeline.yml`, а не из констант поставщика: перехватчик подъёма
(`bindings`, `vendor-watch`), значок проекта, сверка семьи, факты и общий
издатель (`bindings`), гейт рождения правила (`decisions`, `proposals`,
`finding-kinds`, `bindings` — по таблице точки ветвления) и заход подключения
(`area-paths`, `bindings` у потребителя). Битый раздел путей называется
отказом с причиной, а не подменяется умолчанием.
