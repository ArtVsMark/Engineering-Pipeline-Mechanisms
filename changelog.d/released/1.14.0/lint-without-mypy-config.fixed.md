### Шаг `lint` у потребителя без своего Python не краснеет на `mypy` без целей

Голый `mypy` без настройки падал «Missing target module» кодом 2 на каждом
изменении, и потребителю без своего Python оставалось выключить весь `lint`
вместе с `ruff`. Теперь без настройки `mypy` (`mypy.ini`, `.mypy.ini`,
`[tool.mypy]`, `[mypy]`) шаг «типы» говорит «судить нечего» и зелёный.
