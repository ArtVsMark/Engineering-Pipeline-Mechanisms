### Страж толчка без нужного Python судит команду, а не её описание

Когда интерпретатора по планке нет, страж толчка работает запасным разбором и
брал всё событие после ключа `command` — вместе с `description`. Команда
`git status` с описанием «…unpushed commit…» отвергалась как толчок. Теперь
судится только значение `command`, экранированная кавычка его не обрывает.
