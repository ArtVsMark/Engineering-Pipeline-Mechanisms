### Версии Python в фактах — и отдельными работами без матрицы

Вход `python-matrix` общего шага фактов принимает перечень работ через запятую
(`ci.yml:catalogue,catalogue-next-stable`); у работы без матрицы версия берётся
из `python-version` шага `actions/setup-python`. Проект с версиями отдельными
работами больше не теряет раздел `python`.
