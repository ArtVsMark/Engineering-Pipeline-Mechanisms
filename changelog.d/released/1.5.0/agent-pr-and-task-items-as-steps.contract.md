### Открытие изменения и разбор задач — общими шагами; имена их записей составные

`agent-pr` и `task-items` вынесены в общие шаги `step-agent-pr.yml` и
`step-task-items.yml`. Потребитель зовёт их тонким вызовом по тегу и передаёт
секрет по имени: `MERGE_QUEUE_TOKEN` — токен владельца, чтобы автором в общей
ветке был человек, а не приложение (решение по #994); `CLAUDE_CODE_OAUTH_TOKEN`
— ключ разбора. `secrets: inherit` не нужен. Заготовка `onboard.py` печатает
оба вызова.

Записи проверок называются составным именем: `agent-pr` → `agent-pr / agent-pr`,
`task-items` → `task-items / task-items`. Ответ по классам проверок называет их
так же.
