### Общий шаг фактов `step-facts.yml` — один издатель `facts.json` для семьи

Новый шаг собирает `facts.json` по договору витрины: общие показатели выводит
из дерева сам, свои числа проект отдаёт артефактом `extra-facts.json`. Своё
не перекрывает общего, у каждого показателя договора — значение или причина.
Файл сверяется со схемой витрины и кладётся коммитом поверх ветки `badges`,
остальное на ветке не трогается. Входы: `ci-workflow`, `python-matrix`,
`python-next`, `inputs-artifact`, `publish`. Заход подключения печатает его
вызов без своих джобов поставщика.
