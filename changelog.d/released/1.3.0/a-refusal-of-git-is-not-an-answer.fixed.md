### Отказ git читался как ответ — и оба раза в сторону, где механизм врёт уверенно

Внешний взгляд назвал один случай; **замер по всему дереву нашёл второй**.

**Замер 20.09.2026, до починки.** Вызовов внешней команды без `check=True` —
**27**; исход не читается у **трёх**. Прочитаны поимённо, а не сосчитаны:

| место | вердикт |
|---|---|
| `items_left.shallow()` | **настоящий** — назван взглядом |
| `review_map.touches_the_answer()` | **настоящий** — нашёлся замером |
| `preflight.main()` | **ложный**: это вызов своей функции `run`, а не `subprocess.run` — предикат оказался шире предмета |

**`shallow()` отвечал «клон полный» на отказ git.** Пустой `stdout` давал
`False`, дальше `born()` шла по обрезанной истории и возвращала правдоподобную,
но неверную дату — ровно тот ложноположительный случай, о котором
предупреждает докстрока самой функции (находка #149). Теперь незнание читается
как «мелкий»: сторона выбрана та, где механизм **молчит**, а не врёт уверенно
([045](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/045-no-silent-fallback.md)).

**`touches_the_answer()` отвечал «не тронут» на отказ git.** Взгляд не получал
указания сверить карту с дифом, а цена пропуска названа в самом механизме:
ревью, которому подделали карту
([085](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/085-content-from-the-subject-is-untrusted-input-to-the-prompt.md)).
Теперь отказ читается как «тронут»: лишняя строка «сверь с дифом» дешевле
молчания.

**Обе стороны выбраны осознанно и в разные стороны** — это не небрежность.
Признак «клон мелкий» гасит сильный счёт (лучше промолчать, чем соврать);
признак «карта тронута» добавляет строку взгляду (лучше сказать лишнее, чем
пропустить подделку). Сторона выбирается по цене ОШИБКИ, а не по виду кода.

**Проверено откатом, каждая половина:**

* `shallow` снова глотает отказ — краснеет;
* `shallow` всегда «мелкий» — краснеют две соседние проверки, державшие
  сильный признак: выключенный насовсем счёт снаружи выглядел бы работающим;
* карта снова глотает отказ — краснеет;
* возврат — зелено.
