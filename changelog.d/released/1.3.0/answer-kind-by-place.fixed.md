### Находка «об ответе» каталогу определяется по месту, а не по упоминанию файла ответов

Реестр находок относил к роду «об ответе» любую находку, в заголовке которой
где угодно упомянут `.rules/bindings.json`. Такую находку снимает только
изменение, тронувшее файл ответов, поэтому находка о коде, лишь назвавшая
этот файл, не снималась ничем, кроме искусственной правки ответа.

Теперь род выводится из места находки — пути в начале заголовка, а без него
первого пути с расширением. Пометка ревьюера `ответ` остаётся полом. Замер по
архиву находок: упоминают файл ответов 63 находки, место у 50, род сменили 13.
Цена названа в решении владельца (#896): находка, чьё место — запись журнала,
а предмет — расхождение с ответом, теперь о коде. Разбор места у рода и у
замера цепочек теперь один — `findings.place_of`.
