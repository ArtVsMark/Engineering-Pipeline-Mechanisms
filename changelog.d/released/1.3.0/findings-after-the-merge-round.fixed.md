### Находки взглядов после слияния #789, #791, #794, #796

Изменения были слиты, пока на них шли взгляды. Их находки разобраны одним
изменением:

- **Навык в прозе ответа** (#794). Голое имя читается при любом регистре
  слова — «Навык…», «НАВЫК…», и в конце фразы («…навыка role-coverage.»). Точка
  конца фразы именем не считается, а `role-coverage.md` по-прежнему не навык.
  Соседний гейт «навык в прозе назван полем» читает тем же предикатом. Он
  сразу нашёл ответ 146: тот опирается на навык `build-a-gate` прозой, а поля
  `skill` не нёс. Поле добавлено.
- **Правила записи фрагментов** (#796). `ignored: changelog.d/*` снимал и
  `changelog.d/README.md`, хотя это не фрагмент. Теперь README стоит в
  `except` и зовёт релиз-инженера, техписателя и редактора: это документ о
  выпуске. `docs/agent/review.md` называет оба исключения.
- **Вторая посылка развилки архива** (#791). Что `ls-tree` отвечает на
  отсутствующий файл пустым выводом и кодом 0, теперь сверено с настоящим
  git, а не только с подменой. Подготовка репозитория в тесте проверяет свои
  коды, чтобы её сбой не выдавался за неверную посылку.
- **Замер цепочек и сборщик реестра** (#789). Вход у них разный: замер
  считает только комментарии бота, с `--at` и без него. Описание модуля и
  журнал говорят это прямо, а режим без момента закреплён тестом.

**Проверено откатом:**
- образец без регистронезависимого слова;
- прежний просмотр вперёд с точкой;
- README без исключения;
- ответ 146 без поля `skill`.
