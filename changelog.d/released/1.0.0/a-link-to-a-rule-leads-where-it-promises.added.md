Ссылки на правила каталога перестали вести в никуда. Их в дереве **триста**, и
двадцать девять были битыми: номер везде верный, а имя файла писалось по памяти,
близко к смыслу — `046-a-red-must-name-its-cause.md` вместо
`046-name-the-gaps-do-not-level-them.md`.

Цена этого выше, чем кажется. Ссылками на правила проект обосновывает решения:
почти каждый механизм называет правило, из которого вырос. Битая ссылка
обесценивает довод дважды — читатель не может ни проверить его, ни отличить
«правила нет» от «адрес переврали». Площадка отдаёт по такой ссылке 404, и ни
один прогон об этом не говорил.

Гейт сверяет имена с выгрузкой каталога, а не с памятью: каталог публикует `id`
и `slug` каждого правила. Выгрузка не пришла — третий исход, а не «чисто»:
«не спросили» и «всё сошлось» снаружи одинаковы (045).

Разводятся два случая: номера нет в каталоге вовсе и имя не то — «правила не
существует» и «правило есть, адрес переврали» чинятся по-разному (154).
