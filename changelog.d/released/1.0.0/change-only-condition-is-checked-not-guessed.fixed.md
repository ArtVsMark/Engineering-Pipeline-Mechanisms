Проверка «шаг идёт только на изменении» смотрит направление условия, а не
наличие слова «push» в нём. Подстрока есть и у перевёрнутой полярности: шаг с
`== 'push'` пошёл бы ровно наоборот — только там, где предмета нет, — и набор
этого не заметил бы. Теперь условие сверяется равенством, а перевёрнутое
отвергается отдельной проверкой.

На это же условие опирается очередь: она считает пропуск на общей ветке
объявленным состоянием, а не краснотой.

Заодно собран комментарий у джоба `ci-complete`: правка разорвала чужое
предложение пополам, вставив внутрь него две новых строки.
