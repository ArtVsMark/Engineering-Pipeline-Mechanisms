### Сбой сети больше не подменяет базу карты головой изменения

Шаг «собрать карту для взгляда» тянул общую ветку и **не проверял, получилось
ли**: `set -uo pipefail` без `-e`, код возврата `git fetch` не читался. При
сбое сети `FETCH_HEAD` оставался тем, что положил `actions/checkout`, — то есть
головой САМОГО изменения.

**Это ровно та подмена, от которой шаг и заведён.** Ответ каталогу
(`.rules/bindings.json`) пишет тот, кого проверяют: изменение могло объявить
все правила машинными и получить взгляд, которому некуда смотреть
([085](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/085-content-from-the-subject-is-untrusted-input-to-the-prompt.md)).
Гейт `test_the_map_is_taken_from_the_shared_branch` этого не ловил и не мог: он
сверяет ТЕКСТ `--base FETCH_HEAD`, а не то, чем `FETCH_HEAD` окажется в
прогоне. Нашёл внешний взгляд на #120.

Теперь отказ фетча — отказ карты: взгляд идёт без неё и говорит почему. Взять
её с головы нельзя ни при каких условиях.

**Разделитель блока в `$GITHUB_OUTPUT` стал случайным.** В карту попадают
заголовки правил, приходящие по сети из выгрузки соседнего репозитория, не
закреплённой по отпечатку. Строка с постоянным `CLAUDE_MAP_EOF` внутри такого
текста закрыла бы блок раньше времени и дала бы дописать в вывод шага что
угодно.

**Оба экземпляра шага починены разом** — у взгляда на изменение и у позднего:
починка одного конца из двух здесь уже стоила находки
([195](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/195-a-narrowed-predicate-names-its-neighbour.md)).
Оба новых признака держатся гейтами, а не вниманием автора.

## Виды механизма — из одного места

`MACHINE` — набор `gate · pipeline · code` — жил **четырьмя копиями**:
`review_map.py`, `build_facts.py`, `drift.py` и `family.py` (там под именем
`KINDS`, то есть вторым именем разом). Ни одна с остальными не сверялась.

Каталог добавит пятый вид — и правка в трёх местах из четырёх выглядит полной,
а числа, которые они печатают, разъедутся без единого красного
([022](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/022-one-canonical-document.md),
[090](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/090-shared-helpers-move-up-not-sideways.md)).
Набор поднят в `scripts/kinds.py`. Взгляд назвал это прямо: коммит, заведший
четвёртую копию, сам обосновывал отказ от рукописных списков ссылкой на 090.
