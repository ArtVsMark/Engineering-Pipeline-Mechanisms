Изменение, которое только удаляет файлы, получает от гейта журнала объявленный
исход, а не обрыв с трассировкой. Пустой ответ git значил для механизма одно и
то же в двух разных случаях: «изменений нет вовсе» — ошибка входа, и «изменение
всё удалило» — законное состояние. Теперь они разведены.
