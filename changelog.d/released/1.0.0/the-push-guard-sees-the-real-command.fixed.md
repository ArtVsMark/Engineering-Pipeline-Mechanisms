### Сторож толчка увидел настоящую команду и перестал молчать вслепую

Пятая группа разбора реестра **#23** — `.claude/hooks/push_guard.py`.

**Обёртка делала толчок невидимым.** Сторож ловил только буквальное первое
слово `git`, и мимо него проходили `/usr/bin/git push`, `env git push`,
`VAR=1 git push`, `nohup git push` и `bash -c "git push …"` — то есть все
обычные способы написать то же действие. Признак теперь ИМЯ программы, а не
строка вызова: путь до неё дело окружения, а не намерения. Список обёрток
закрытый и каждая названа (068); у раскрытия вложенных оболочек есть предел,
и он — не пропуск.

**Слепой сторож махал рукой.** Отказ `git rev-parse` отдавался пустой строкой
— той же, что и отсоединённая голова, — и половина проверки, «толчок мимо
своей ветки», исчезала МОЛЧА. Докстрока при этом уверяла, что пусто бывает
только при отсоединённой голове; на деле пусто бывает и когда git не нашёлся,
и когда каталог не репозиторий. Теперь такой толчок отвергается: толчок
необратим, отправленную ветку окно удалить не может, и цена этого уже оплачена
(#116). Запрет на общую ветку при этом спрашивается ПЕРВЫМ — его причина
точнее, и читателю нужна именно она.

Подделка git в наборе научилась отказывать, поэтому слепота сторожа
проверяется отказом, а не рассуждением (140).
