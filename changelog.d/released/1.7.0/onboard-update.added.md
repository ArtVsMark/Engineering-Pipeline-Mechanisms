### `onboard.py --update`: обновление нашего до нового выпуска

Вторая дверь рядом с `--write`. Наш файл сверяется с заготовкой своего тега
по существу вызова: адрес без тега, секреты, события, права. Входы
`with:` — данные проекта: они переносятся в новую заготовку.
Совпал — переписывается новой заготовкой. Разошёлся — отказ на всё
обновление (исход 7) с разницей для задачи `consumer-gap`. В `ci.yml`
поднимается только тег наших строк, новые шаги печатаются. `.pipeline.yml`
и свод не трогаются. Порядок — `docs/use/onboarding.md`.
