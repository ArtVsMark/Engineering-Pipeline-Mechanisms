### Значки семьи стоят в шапке README

Шесть значков — правила, семья, версия, выпуск, скрипты, покрытие — стоят в
шапке README под заголовком, каждый ссылкой на свой источник. Рисует их
shields по JSON-описаниям на ветке `badges` с `cacheSeconds=300`; свои SVG
сборка больше не рисует и не публикует.
