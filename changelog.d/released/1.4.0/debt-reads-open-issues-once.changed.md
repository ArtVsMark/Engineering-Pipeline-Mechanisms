### Шаг `debt` читает список открытых задач один раз за прогон

Шаг `debt` искал четыре живые задачи по маркеру и считал пункты задач. Каждый
из пяти счётов читал список открытых записей у площадки сам — пять запросов из
квоты прогона на один и тот же ответ. Теперь список читается один раз и
передаётся всем пяти. Поиск живой задачи (`findings.live_issue`) принимает
готовый список; без него читает сам, как прежде. Кэша в `findings` нет
намеренно: писатель реестра по устаревшему списку положил бы запись по
прежнему телу.

**Замер 03.10.2026** (счётчик запросов, живой прогон `debt`): чтений
`issues?state=open` — 5 → 1.
