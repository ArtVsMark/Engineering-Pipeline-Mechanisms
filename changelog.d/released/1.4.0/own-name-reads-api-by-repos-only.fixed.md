### Гейт имени берёт имя только с хостов, где путь — `<владелец>/<имя>`, и не зовёт «чисто» несверенное

`check_own_name.py` считает именем репозитория адрес на трёх хостах —
`github.com`, `www.github.com`, `raw.githubusercontent.com` — и на хостах API
(`api.github.com`, `uploads.github.com`) только путь `/repos/<владелец>/<имя>`.
Всё прочее — `gist.`, `avatars.`, `user-images.`, `user/repos`, `gists/…` — не
имя и запроса не стоит. Хост читается целиком, с поддоменом.

Имена, на которые площадка не ответила, печатаются числом, и строка начинается
со «чисто по ответившим», а не с «имена совпадают». Не ответила ни на одно —
третий исход: протухший токен или кончившаяся квота сверяют ноль имён, и
«чисто» было бы ложным.
