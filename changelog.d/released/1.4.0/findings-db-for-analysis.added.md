### База находок для анализа собирается из архива

`scripts/findings_db.py` собирает SQLite из одного или нескольких архивов
находок (`findings.json`) — для запросов вроде «какой род повторяется у
какой роли», «какие места получают находки заход за заходом», «какое
правило каталога держит род находок» (представление `finding_rules`).
Источник остаётся JSON: база каждый раз собирается заново и никуда не
коммитится, а на чужой форме архива сборка отказывает с причиной, а не
собирает молча. Нужна только стандартная библиотека. Представление
`finding_rules` держит каждую находку с родом: род, ещё не записанный в
архив, оставляет её с пустым ответом каталогу, а не роняет.
