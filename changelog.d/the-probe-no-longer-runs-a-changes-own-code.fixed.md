### Поверхность: замер взведения идёт только кнопкой и по названному номеру

**Переход одной строкой:**

```
было:  arm.yml — on: pull_request (paths: scripts/arm.py …); предмет выбирал сам заход
стало: arm.yml — on: workflow_dispatch с обязательным входом `pr`; предмет называет человек
```

Причина — находка внешнего взгляда на #231 (`b41a6ce`), и она серьёзная: на
событии изменения прогон исполнял код **из самого изменения**, держа в
окружении `MERGE_QUEUE_TOKEN`. Любая правка `scripts/arm.py` в ветке
становилась кодом, которому выдали токен владельца. Своё подтверждение прогоном
замер уже получил 12.09.2026, а взведение живёт теперь в шаге 8 — там прогон
берёт файлы с общей ветки, а не из изменения.

Заодно закрыты три соседние находки того же взгляда:

- **предмет больше не выбирается заходом** (`47c0b03`, `5d076a7`): шаг обходил
  живые изменения и брал первое подходящее — то есть трогал ЧУЖУЮ работу,
  выбранную порядком ответа площадки
  ([053](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/053-queue-order-is-a-rule-not-arrival.md));
- **отмены у прогона нет** (`e189694`, `0d569d4`): заход, убитый между
  взведением и снятием, оставлял значок висеть. Теперь `cancel-in-progress:
  false`, а брошенный значок всё равно снимет очередь — шаг 8 держит взведённой
  ровно одну голову и снимает всё прочее
  ([109](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/109-every-exit-from-a-transient-state-must-be-terminal.md));
- **ввод кнопки идёт окружением**, а не подстановкой в текст команды: чужая
  строка внутри нашей оболочки — это исполнение чужого
  ([085](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/085-content-from-the-subject-is-untrusted-input-to-the-prompt.md)).

И две находки по соседям: снятие согласия в очереди больше не трогает
изменения с **чужой базой** (#232, `9459ea9`) — предмет очереди это вставка в
её собственную ветку; а `items.names_of` не чистит руками то, что снимает само
приведение (#233, `e480bdc`, `808c2d6`).
