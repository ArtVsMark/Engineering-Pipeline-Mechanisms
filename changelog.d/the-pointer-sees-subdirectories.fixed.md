### Гейт указателя смотрит и во вложенные каталоги `docs/`

Поздний взгляд на [#841](../../pull/841). Проверка состава указателя
`docs/README.md` обходила только корень `docs/`, хотя указатель обещает
«каждый документ». Документ в подкаталоге выпадал из сверки, в том числе тот,
который перенесут по #840.

Теперь обход глубокий. Архив решений `decisions/` назван в указателе
целиком, по закрытому списку с причиной: к решению приходят по номеру, а
читатель у каждого решения свой. Любой другой подкаталог обязан назвать
каждый свой документ. Строка о решениях вынесена из раздела разработчика и
стоит для всех читателей.

**Проверено откатом:** если убрать из указателя ссылку на `decisions/`,
краснеет проверка состава.
