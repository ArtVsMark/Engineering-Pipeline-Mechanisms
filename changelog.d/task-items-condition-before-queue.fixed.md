### Разбор задач: незлитое закрытие больше не снимает ожидающий разбор

Условие «только слитое» стоит в вызове `task-items.yml` до группы очереди, а
не только внутри шага: иначе закрытие без слияния вытесняло из очереди
ожидающий разбор слитого изменения. Скопировавшим вызов — перенести строку
`if:` из шага в свой джоб.
