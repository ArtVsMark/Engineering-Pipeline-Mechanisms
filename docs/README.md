# Документы по читателю

> **Читатель:** любой, кто ищет нужный документ. Здесь только указатель:
> кому что читать. Содержание — в самих документах.

Документы делятся не по темам, а по читателю: каждому нужно своё, и одно из
другого не выводится
([021](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/021-split-docs-by-reader.md)).
Раздел документу выбран по его объявленному читателю — первым строкам самого
документа, — и документ с несколькими читателями стоит у каждого. У каждого
предмета один канонический документ; в остальных — ссылка на него
([022](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/022-one-canonical-document.md)).
**Предел назван:** что каждый документ `docs/`, и во вложенных каталогах
тоже, есть в указателе, держит
`tests/test_docs_shape.py`, а совпадение раздела с объявлением сверяется
чтением — текст объявления машина не сравнивает.

## 🤖 Окну, которое работает в проекте

| Документ | Когда читать |
|---|---|
| [`AGENTS.md`](../AGENTS.md) | первым, при старте: что проект требует от любого агента |
| [`CLAUDE.md`](../CLAUDE.md) | вторым: чем агентское окно отличается от любого другого |
| [`roadmap.md`](roadmap.md) | когда ведёшь работы: порядок и признаки готовности |
| [`gaps.md`](gaps.md) | когда берёшь работу: что ещё не доказано прогоном |
| [`behaviour.md`](behaviour.md) | когда реализуешь или ведёшь конвейер: контуры, состояния, путь взгляда |
| [`roles.md`](roles.md) | когда отвечаешь от лица роли: вход, артефакт, запрет, предел |
| [`directions.md`](directions.md) | перед крупной работой: какие вопросы о продукте здесь задают |
| [`pipeline.md`](pipeline.md) | когда подключаешь проект к механизмам: шаги, файлы, правила формы |

## 🧩 Соседу, который подключает механизмы к своему проекту

| Документ | Когда читать |
|---|---|
| [`README.md`](../README.md) | что это такое и стоит ли брать |
| [`onboarding.md`](onboarding.md) | когда уже решил брать: как подключиться |
| [`pipeline.md`](pipeline.md) | какие шаги и файлы приезжают к тебе |
| [`release.md`](release.md) | когда твой проект прибит к версии |

**Решения** ([`decisions/`](decisions/)) — архив для всех читателей: почему
сделано так. К решению приходят по номеру из задачи, коммита или ответа, а
читатель у каждого свой и объявлен в его первых строках; поэтому каталог
назван здесь целиком, а не разложен по разделам.

Раскладка файлов по подкаталогам читателя — отдельная работа
([#840](../../issues/840)).
