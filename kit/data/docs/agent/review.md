# Процедура внешнего взгляда: кем смотреть на изменение

> **Читатель:** внешний взгляд — чем проект проверяет изменение.

Заготовка механизмов (#1386). Карта взгляда читает этот файл с общей ветки и
отдаёт его взгляду целиком: задание взгляда общее для семьи и о проекте не
говорит ничего, предмет называет этот файл.

## Что держит проект

> **Наполнение проекта:** что проект держит и по каким документам читать
> изменение — договор, свод, где живут правила. Заголовок раздела взгляд ищет
> буквально, переименовывать его нельзя.

## Роли: обязательные и по контексту

Кем смотреть, говорит таблица ролей взгляда (`bash .claude/mechanisms.sh paths.py review-roles`):
обязательные роли идут на каждом изменении, контекстные — по тронутым путям.
Профили ролей — `bash .claude/mechanisms.sh paths.py roles`.

> **Наполнение проекта:** почему обязательны именно эти роли и что зовёт
> остальные.
