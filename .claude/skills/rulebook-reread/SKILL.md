# Перечитать свод, не перезапуская окно

> **Читатель:** окно, которое уже работает, и чей свод мог смениться.

## Зачем это существует

Свод читается окном **один раз, при старте**. Правка `AGENTS.md` или
`CLAUDE.md`, попавшая в общую ветку позже, живому окну **не видна**: оно
продолжает работать по прежним правилам и не знает об этом. Правило каталога
[047](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/047-rule-change-restarts-the-windows.md)
говорит: такие окна перезапускают, а не рассылают им письма.

**Навык — машинная половина этого правила.** Он читается **в момент вызова**, а
не при старте окна, и потому показывает свод живым. Перезапуск от этого не
отменяется: решает человек. Но выбор у него появляется.

Замер 16.09.2026 по 381 коммиту общей ветки: правок свода 56, и **семь раз**
свод менялся под уже работающим чужим окном.

## Что сделать

**1. Прочитать свод целиком, с диска, сейчас.**

```
AGENTS.md    — что проект требует от любого агента
CLAUDE.md    — что верно для агентского окна и бессмысленно для другого агента
```

Читать **файлы**, а не пересказ из своей памяти: пересказ и есть то самое
устаревшее знание, ради которого навык заведён.

**2. Узнать, что именно сменилось под окном.**

```bash
python scripts/check_rulebook_fresh.py --base origin/main --head HEAD
```

Шаг называет правки поимённо. Их разбор:

```bash
git show <хэш> -- AGENTS.md CLAUDE.md
```

**3. Назвать вслух расхождение, а не молча исправиться.** Если прежнее
поведение окна разошлось с новым сводом — сказать владельцу, **что** окно делало
по старому правилу и **где** это уже уехало в общую ветку. Молчаливая поправка
прячет след
([154](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/154-none-must-name-its-reason.md)).

**4. Решение о перезапуске — владельца.** Навык его не заменяет. Признаки, по
которым не ждут календаря, перечислены в `CLAUDE.md`, раздел «Когда окно
перезапускают»: окно перечитывает уже прочитанное, противоречит себе внутри
смены, пересказ прошлого занимает больше сегодняшней работы.

## Чего этот навык НЕ делает

- **Не заменяет перезапуск.** Он даёт живому окну увидеть свод; всё, что окно
  успело сделать по старым правилам, уже сделано.
- **Не правит свод.** Правка свода — отдельная работа, и она проходит обычным
  изменением.
- **Не отменяет шаг `rulebook-fresh`.** Невызванный навык неотличим от
  вызванного и проигнорированного; видимым расхождение делает шаг, а не навык.
